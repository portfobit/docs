ChatGPT Desktop (Chat and Codex modes) and Codex CLI connect to Portfobit's remote MCP server with browser-based OAuth. You do not need to create or paste an API key.

## Recommended: install the plugin with a prompt

Paste this into ChatGPT Desktop, in Chat or Codex mode, or into Codex CLI:

```text
Install the Portfobit plugin from https://github.com/portfobit/portfobit-plugin using the Codex plugin marketplace, then guide me through Portfobit browser OAuth.
```

Install once: the plugin and its connector then appear in both ChatGPT Desktop modes and in Codex CLI. Sign in to Portfobit in the browser when asked, and choose only the scopes you want to grant.

## Manual Remote MCP setup

These commands are for Codex CLI.

1. Add the Portfobit MCP server:

```bash
codex mcp add portfobit --url https://mcp.portfobit.com/v1/mcp
```

2. Start the OAuth login:

```bash
codex mcp login portfobit
```

3. Sign in to Portfobit in the browser and choose the scopes you want to grant.
4. Ask Codex: **“Use portfobit to list the account connectors I can connect.”**

If an existing `portfobit` configuration has a static `Authorization` header, remove it before logging in with OAuth.
