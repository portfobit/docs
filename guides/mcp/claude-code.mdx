Claude Code connects to Portfobit's HTTP MCP server with browser-based OAuth.

## Recommended: Install the Portfobit plugin

Paste this into Claude Code:

```text
Install the Portfobit plugin from https://github.com/portfobit/portfobit-plugin using the Claude Code plugin marketplace, then guide me through Portfobit browser OAuth. Then help me connect my first exchange account using https://docs.portfobit.com/guides/connect-your-first-account.
```

The same prompt works in Claude Desktop Code mode. For Chat/Cowork mode, see [Claude Desktop](/guides/mcp/claude-desktop).

## Manual Remote MCP setup

1. In a terminal, add the remote server:

```bash
claude mcp add --scope user --transport http portfobit https://mcp.portfobit.com/v1/mcp
```

2. Start the OAuth login:

```bash
claude mcp login portfobit
```

3. Sign in to Portfobit in the browser and choose the scopes you want to grant.
4. Run `claude mcp list` to confirm that `portfobit` is registered.
5. Ask: **“Use portfobit to list the account connectors I can connect.”**

If an existing configuration has a static `Authorization` header, remove it before logging in with OAuth.
